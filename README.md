# Manifold
Manifold is an exam project and an idea of making a selfhostable cloud *platform*

### Platform?
Yes, this project isn't a storage out of the box. It's a platform that lets you manage many different storage buckets no matter where they are hosted.

## Features

* Full isolation. Manifold isn't aware of any files that aren't part of its metadata database.
* Authentication, you can use this project in local networks and manage roles and bucket access for users
* Robust and distributed, powered by .NET and Aspire
